# Threat Level Indicator

A standalone, general-purpose threat gauge with security advice that stays constant at every level. The goal is sustainable security, not the more common approach of flip-flopping between complacency and paranoia.

Each day’s threat calculation starts at Low. It then adds one level on Friday, Saturday, or Sunday; and one level on any U.S. holiday or the day before one. It uses the visitor's local date. A visitor with additional threat intelligence may choose to manually update the day’s threat level. It refreshes automatically at local midnight.

The site is prepared for GitHub Pages at `threat.gridscout.net`.
