# Threat Level Indicator

A standalone, one-page threat level indicator with a manual four-level gauge and security advice that stays constant at every level.

The page starts at Moderate, or High when a selected U.S. holiday falls within the next seven days. It uses the visitor's local date. It does not use a live threat feed or send data to a server.

The site is prepared for GitHub Pages at `threat.gridscout.net`.
